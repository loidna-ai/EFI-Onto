## 입력 구조

| JSON 목록 | 필드와 의미 |
|---|---|
| `examinations` | 기존 절연 재질에 `insulation_material_basis`, `insulation_filler`, `insulation_filler_basis` 추가. 충전재는 `CalciumCarbonate`, `Other`, `None`, `Unknown` |
| `insulation_exposures` | 같은 절연재의 개별 가열(`Heating`) 또는 표면 수분(`SurfaceMoisture`) 기록. 각 기록에 독립된 확인 상태·출처·작성 주체 |
| `insulation_history_reviews` | 식별 기록, 검토할 가열·수분 기록 한 쌍, 선택적 발화 사건, 원문과의 적용 조건 대조 근거를 연결 |

가열 기록은 `temperature_min_C`·`temperature_max_C`(섭씨, 유한한 Decimal), `temperature_basis_kind`(`Measured`, `Reconstructed`, `Unknown`)를 받는다. 온도 하한이 상한보다 크면 위반이다. 원자료가 한 값이면 양쪽에 같은 값을 넣고 측정 오차·위치·추정 방법을 `exposure_basis`에 남긴다. 온도를 모르면 비워 둔다. 없는 온도를 0으로 바꾸지 않는다.

표면 수분은 `moisture_presence`(`Present`, `Absent`, `Unknown`)와 `moisture_origin`(`AmbientAir`, `DirectWater`, `Other`, `Unknown`)으로 기록한다. 대기에서 온 수분과 직접적인 물 노출은 별도다. `Absent`는 확인된 건조 관찰 기록일 때 사용한다. 미조사·확인 불가는 기록 상태 `Missing`·`Unverifiable`와 `Unknown`으로 남긴다. 수분 부재 기록은 습윤 사건이 되지 않는다.

`earliest`·`latest`는 노출의 발생 가능 시간 범위, `observed_at`은 자료를 확인한 시각이다. 시간 범위 전체에서 해당 온도가 유지됐다는 뜻은 아니다. 가열 지속 시간이나 반복 주기 등 추가 조건은 원자료와 `exposure_basis`에 남겨 검토한다. 여러 가열·습윤 이력을 각각 저장할 수 있으며 한 검토는 지정한 기록 한 쌍만 다룬다. 이 검토의 완료가 대상의 전체 사용 이력 수집 완료를 뜻하지 않는다.

## 검증 결과의 의미

`insulationHistoryDocumented`는 다음을 확인한 **자료 연결 결과**다.

1. 같은 세션·같은 실제 절연재의 확인된 식별·가열·수분 기록이다.
2. 재질·충전재의 알려진 값과 각각의 근거가 있다.
3. 가열 온도 범위, 측정 또는 재구성 구분, 발생 시간 범위·근거가 있다.
4. 표면 수분의 존재 또는 부재, 발생 시간 범위·근거가 있다. 존재한다면 유래도 식별해야 한다.
5. `applicability_basis`에 실제 기록을 원문 조건과 대조한 근거가 있다.

따라서 PVC가 아닌 재질, 충전재 부재, 110°C 미만의 가열도 자료를 완비하여 ‘본문 조건과 다르다’고 검토할 수 있다. **자료가 완비됐다는 결과는 본문 메커니즘의 성립·적용 적합성을 승인한 결과가 아니다.** 대조 근거의 실질 타당성은 조사관이 원자료로 검토해야 한다. 자유 서술의 타당성을 자동 판정하지 않는다.

`assessment_complete: true`인데 위 자료가 부족하면 SHACL 위반이다. 미완료 기록은 저장할 수 있으며 추가 확인 질문이 나온다. 필수 값 누락·미확인을 원인 반증이나 사건 부재로 해석하지 않는다.

`claim_pre_ignition_sequence: true`는 별도 주장이다. 확인된 기록의 **가열 최후 시각 < 수분 존재 최초 시각**, **수분 존재 최후 시각 < 발화 최초 시각**을 요구한다. 발화는 같은 계통의 확인된 `Ignition` 사건이어야 한다. 수분 부재·사후 습윤·서로 겹치는 시간 범위·관찰 시각만 있는 자료는 이 주장을 뒷받침하지 못한다. 조건을 만족하면 `preIgnitionHeatingMoistureSupported`를 얻는다. 이 결과도 가열이 습윤을 일으켰다는 인과 추론은 아니다.

기록은 `hasInvestigationRecord`에 저장된다. 가열·습윤 관측은 T06의 검증 근거로 인용할 수 있지만 이력 검토 의견 자체를 관측 증거로 인용할 수는 없다.
