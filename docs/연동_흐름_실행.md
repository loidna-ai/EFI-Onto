# 연동 흐름을 처음 끝까지 돌렸다 — 설계계획서 7.4 의 실행과 거기서 드러난 것

2026-09-04. `scripts/run_case.py`. 사례 하나를 판독 → 가설수립 → 변별 질의 → 조사서로 응답 → 재평가 →
확정 검사 → SHACL 검증 → PROV 경로 보고서까지 이어 돌린다. 지금까지 이 흐름을 이어 붙여 돌린 적이
없었다. 평가(`eval.py`)는 조사서의 사실을 전부 한 번에 넣는다.

```
python scripts/run_case.py UIJEONGBU_2025_055     # 보고서 build/run_<case>.md · .ttl
python scripts/run_case.py --all                  # 150건 대화 루프 요약
```

**시뮬레이션 방식.** 사진 층 사실(손상 양상)만 먼저 준다. 온톨로지가 고른 질의에 조사서에 실제로 적힌
사실로만 답하고, 없으면 결측(Missing)으로 답한다 — 결측은 부정 확인이 아니다(P4). 질의 선택이 조사서에
있는 것을 묻는지, 몇 번 물어야 판정에 이르는지가 드러난다.

## 드러난 것 넷 — 전부 시험이 잡지 못하던 것

### 1. SHACL 은 `supportedBy` 를 만든 적이 없었다

결론 제약 열 개 남짓(C-2·C-5·C-23·C-56·C-57·C-59…)이 `supportedBy` 를 **읽는데** 어떤 규칙도 만들지
않았고, Python 직렬화도 쓰지 않았다. 시험은 ABox 에 손으로 적어 넣어 통과했다. 실제 세션에서는 전부
빈 목록을 봤다 — 즉 실제 결론 검증이 구조적으로 죽어 있었다. F-4 가 지지 근거를 남기도록 했다(F-1 이
`refutedBy` 를 남기는 것과 대칭). `test_shacl_derives_supported_by_like_python`.

### 2. F-4 가 같은 사실을 두 번 셌다

F-4 는 (규칙, 사실) 쌍마다 더했고 Python 은 규칙당 한 번 더한다. 실제 사례 19건에 같은 클래스의 사실이
둘 이상 있다(헐거움 13건). 트래킹 사례에서 Python 72 대 SHACL 87 로 갈렸다. CLAUDE.md 가 "두 곳이
갈리면 안 된다"고 못 박은 지점이다. DISTINCT (규칙, 가감점)으로 합산한다.
`test_duplicate_facts_count_once_in_both_engines`.

### 3. 질의 선택기가 접촉불량 vs 압착손상에 고착됐다

사진만으로 아홉이 50점 동점이면 '상위 둘'은 목록 순서상 앞의 둘이라, 접속 상태·아산화동을 147회·114회
묻고 대부분 결측이었다. 150건에서 정답 가설이 **형성조차 안 된** 것이 74건. 그리고 형성 질의를 잎
단위(인장? 진동? 굴곡?)로 물어 조사서가 '반복 굴곡'을 적어도 "인장?" 에는 결측으로 답했다.

고친 것 — 동점이면 동점 전부가 후보이고, **세워지지 않은 가설의 필요조건을 그것이 선언된 수준(공통
상위)에서 먼저 묻는다.** D-15 의 근거인 §19.4.1 "자료에서 가설을 세운다"가 질의 순서의 근거이기도 하다.
`test_query_selection_forms_hypotheses_before_scoring_them`.

| 질의 한도 | 고치기 전 | 동점·형성 우선 | + 필요조건 수준으로 | 전체 사실 한 번에 (`eval.py`) |
|---:|---:|---:|---:|---:|
| 6 | — | — | **122 / 150** | — |
| 8 | 75 | 79 | **123 / 150** | — |
| 12 | — | 103 | 124 / 150 | — |
| 24 | — | 123 | — | — |
| ∞ | | | | 126 / 150 |

**6회 안에 전체 사실을 다 준 결과의 97% 를 회수한다.** 남은 셋은 조사서에 필요조건이 없는 사례다 —
대화로는 회수되지 않는다.

### 4. 점수 확정 ≠ NFPA 확정

점수·질의 수로 확정 조건이 차도(`conclusion_check`) SHACL 결론 제약은 통전 확인(C-57), 최초 착화물·
열전달(T04), 확신도(C-14), 아크 시작 설명(C-33), 대안 가설 판정(C-24), 발화 순서 일곱 요인(C-44)을
따로 요구한다. 그중 통전은 변별력이 0 이라 질의 후보에 오르지 않아 조사서에 있는데도 70건을 끝내 안
물었다. `Session.prerequisite_slots()` 가 C-57 을 확정 전제로 묻는다. 나머지(착화물·열전달·확신도)는
사실이 아니라 **기록**(T04)이라 대화 루프가 아니라 조사관 입력이 채운다 — 보고서가 그것을 목록으로 낸다.
