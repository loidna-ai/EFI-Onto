# T07 — 접속 방식·나사 재질·체결값

2026-09-03. 접속 구조와 토크를 관찰·출처·제품 조건에 연결했다. T01의 계통 연결과 T06의 검증 기록에서 사용할 수 있다. 특정 접속 방식이나 나사 재질을 접촉불량으로 분류하거나, 기준보다 낮은 토크를 발화 원인으로 자동 확정하지 않는다.

## 원문 대조와 결정

| 원문 | 이번에 반영한 내용 | 적용 경계 |
|---|---|---|
| NFPA 921 (2024) §9.8.2.2 | 도체·단자·기기의 연결, 단자 표시와 도체 고정 방식 | 배선 뒤쪽의 구멍만 보고 스프링 고정식이라고 분류하지 않음 |
| Ignition Handbook p.759 | 나사 재질과 식별 근거, 도금 외관과 자석 반응의 구분 | 재질 판정은 출처가 있는 별도 기록. 자석 흡착·비흡착에서 강철·황동을 자동 도출하지 않음 |
| Ignition Handbook p.760 | 스프링 장력으로 유지하는 삽입식과 삽입 후 나사를 조이는 구조의 구분 | 특정 시험의 저항·고장률을 모든 제품의 위험도나 점수로 쓰지 않음 |
| Ignition Handbook p.759, p.764 | 토크 기준의 대상 제품·도체·접속 방식·측정 종류와 출처 | 문헌 시험값과 실제 제품의 제조사 기준을 구분 |

**0.7 N·m 설명은 p.759의 특정 14 AWG 구리선·기존 콘센트 시험이다.** p.764에는 Hicks 등의 접속 방식·금속·시험 조건별 결과가 있다. 기존 서식의 “p.764 최소 토크 0.7 N·m”라는 단축 표기는 바로잡았다. 이 숫자를 공통 적합 기준이나 기각 문턱으로 추가하지 않았다.

원문은 나사 체결 이후 배선을 함에 넣는 취급으로 접속이 느슨해질 수 있다는 조건도 설명한다(p.764). 따라서 설치 당시 적용 토크가 확인돼도 그 상태가 발화 때까지 유지됐다고 추론하지 않는다.

## 입력 구조

| JSON 목록 | 기록하는 내용 |
|---|---|
| `terminations` | 연결 도체, 개별 단자, 소속 기기, T01 연결 기록, 고정 방식, 도체 재질·크기, 제품 식별자, 단자 표시, 식별 근거 |
| `fasteners` | 실제 단자 나사·볼트, 소속 접속 기록, 판정 재질, 자석 반응, 식별 방법·근거 |
| `torque_measurements` | 대상 접속·나사, 측정값(N·m), 토크 종류, 실제 측정 시각, 발화·사후 취급에 대한 시점, 계측 방법·시각 근거 |
| `torque_references` | 제조사·연구·기타의 구분, 적용 제품·접속 구조·도체·필요 시 나사 재질, 토크 종류, 하한·상한, 문서 출처·적용 범위 |
| `torque_comparisons` | 측정과 기준의 연결, 적용 근거, 비교 완료 주장, 발화 전 적용 토크 주장 |

각 기록은 확인 상태·출처·작성 주체를 가진다. 미확인·미측정은 `Unknown`·`Missing`·`Unverifiable`로 남긴다. 빈 값을 0 N·m 또는 부재 확인으로 바꾸지 않는다. `terminal_marking`에 색·극 표시를 기록할 수 있지만 색만으로 실제 접속 상태를 도출하지 않는다.

접속 방식의 값은 다음과 같다.

| 값 | 의미 |
|---|---|
| `ScrewTerminal` | 나사·볼트로 도체를 고정하는 단자 |
| `PushInSpring` | 도체를 삽입하고 스프링 장력으로 유지하는 구조 |
| `PushInScrewClamp` | 삽입한 도체를 나사 조임으로 고정하는 구조 |
| `WireWrapPin` | 핀에 도체를 감는 접속 |
| `Soldered`, `Crimped` | 납땜, 압착 접속 |
| `TwistOnConnector`, `Twisted` | 트위스트 커넥터, 도체 꼬임 접속 |
| `Other`, `Unknown` | 이 목록으로 특정하지 못한 구조, 미확인 |

`Other`·`Unknown`은 보관할 수 있지만 구조 식별 완료나 제품 기준 비교에 사용하지 않는다. 납땜 방식 입력이 추가됐다는 이유로 T08의 납땜 균열·형성 시점 경로를 완료 처리하지 않는다. 도체 금속·크기 입력도 T15의 산화 특성이나 T16의 허용전류 계산을 대신하지 않는다.

## 토크 비교 조건

`torqueComparisonSupported`는 다음 조건을 SHACL로 확인한 경우에 산출된다.

1. 출처가 있는 확인된 도체·단자·기기 연결과 접속 구조가 있다.
2. 실제 제품의 제조사 기준이며 제품 식별자·접속 방식·도체 재질·크기·토크 종류가 일치한다.
3. 기준에 나사 재질 제한이 있으면 같은 단자의 해당 재질 식별 기록이 확인돼 있다.
4. 측정값·측정 종류·측정 시점·계측 방법과 적용 근거가 있다.
5. 기준 하한·상한 중 적어도 하나가 있고, 둘 다 있으면 하한이 상한보다 크지 않다.

제품 식별자는 제조사·모델·개정 등을 구분할 수 있게 입력한다. 도체 크기도 단위를 포함한다(`14 AWG`, `2.5 mm²` 등). 현재는 정규화한 동일 표기의 일치를 사용하며 AWG↔mm² 변환이나 다른 제품 간 동등성을 추정하지 않는다. 기준 문서의 실제 적용 적합성은 `applicability_basis`에 근거를 남기고 조사관이 검토한다.

측정 종류는 `AppliedTightening`(실제 적용한 조임 토크), `ResidualTightening`(잔류 조임 방향 토크), `BreakawayLoosening`(풀림 개시 토크)로 구분한다. 서로 다른 종류를 같은 양으로 비교하지 않는다. 수치 입력은 N·m 단위의 `Decimal`이며, 음수·무한대·NaN은 허용하지 않는다. 다른 단위의 원자료를 환산했다면 출처·계측 방법에 원값과 환산 근거를 남겨야 한다.

비교 결과는 `BelowMinimum`, `AboveMaximum`, `WithinRange`, `AtOrAboveMinimum`, `AtOrBelowMaximum` 중 하나다. 한쪽 기준만 있으면 다른 쪽 한계를 만들어내지 않는다. 결과는 그 측정값과 기록된 기준의 대조이며 접촉압이나 원인 판정이 아니다.

`Study`·`Other` 참고자료는 보관할 수 있지만 제품 기준 비교 완료를 뒷받침하지 않는다. 제품 문서가 없으면 적용 근거와 확인 질문을 남긴다.

## 발화 전 기록과 사후 측정

측정 시점을 `BeforeFire`, `AsFoundAfterFire`, `AfterHandling`, `Unknown`으로 기록한다. 출처를 읽고 기록한 `observed_at`과 실제 측정·체결 시각 `measured_at`을 구분한다.

`claim_pre_fire_applied_torque: true`를 주장하려면 위 비교 조건 외에도 실제 적용 토크 기록, 발화 전 시점 근거, 같은 계통의 확인된 발화 사건 시간 범위가 필요하다. 실제 적용 시각은 발화의 최초 가능 시각보다 빨라야 한다. `BeforeFire`라는 표기만 있거나 사후 관찰 시각만 있는 입력은 통과하지 못한다.

사후 재체결을 제조사 기준과 비교하는 것은 가능하지만 발화 전 적용 토크로는 쓸 수 없다. 발화 전 적용 시각이 확인된 기록도 발화 당시의 잔류 체결 상태를 보장하지 않는다. `LooseConnection`·`InsufficientContactPressure`·점수·결론은 자동 생성하지 않는다.

## 실행과 검증

```powershell
python scripts/investigate.py examples/investigation_t07.json --output build/investigation_t07_report.json
```

예제의 제품·제조사 기준·계측 기록은 모두 합성 자료다. 실제 제품에 적용할 수치가 아니다. 예제는 발화 전 적용 토크의 제품 기준 대조와, 그 기준에 적용할 수 없는 사후 풀림 토크를 함께 보여 준다. `conforms: true`, 위반·권고 0개, 세부 확인 질문 1개를 반환한다.

새 시험 17개는 구조·제품·재질 불일치, 미확인 연결, 자석 반응의 오분류 방지, 연구값 적용 차단, 토크 종류·시간 구분, 단측 기준·역전 범위·정밀도·다른 세션 참조를 검사한다.

전체 **122개 테스트 통과(432.31초)**, OWL 불만족 클래스 **0개**, lint **0건**을 확인했다. 기존 150건은 **정확 126·오판 8·판단보류 16**으로 유지됐다. T07 완료 시점의 대조표상 NFPA 하위 절은 **88/100**, Babrauskas는 **58/69**이며 분모와 가설·점수 규칙은 유지했다. 검증 로그와 전체 상태는 [인계](인계.md)를 참조한다.

기존 보류 항목 T08~T11·T13의 결정을 유지한다. 후속 [T14](T14_구현.md)·[T15](T15_구현.md)·[T16](T16_구현.md)도 구현했다. 다음 설계검토 순서는 **T17: 본딩 경로와 임피던스 근거**다. 세부 상태는 [미완료 목록](TBox_미완료_목록.md)을 참조한다.
