# T15 — 도체·접속 금속 조합과 산화 특성

2026-09-04. NFPA 921 (2024) §9.7.2.1과 Babrauskas, *Ignition Handbook* p.550·pp.762–765를 대조했다. 도체 하나의 재질만 저장하던 T07을 실제 접점 금속·도금과 설치 맥락까지 확장하고, 문헌의 적용 범위를 항목별로 검증한다. 기록이나 문헌 조건의 일치에서 접촉불량·발광 접속·원인 가점을 생성하지 않는다.

## 원문 대조

| 원문 | 표현한 내용 | 적용 경계 |
|---|---|---|
| NFPA §9.7.2.1 | 알루미늄 분기배선은 적합한 접속기기가 필요하고, 대형 알루미늄 케이블은 인입선에도 쓰인다는 설치 맥락 | 알루미늄이라는 이름만으로 접속 불량을 만들지 않음. 도체 크기·분기회로/인입선 용도·승인 상태를 각각 기록 |
| NFPA §9.7.4.1 | 순알루미늄의 산화막 안 용융 형상 | 기존 `PureAluminumConductor`와 합금 도체의 구별을 유지. T15 입력에서도 `PureAluminum`과 `AluminumAlloy`는 별도 값 |
| Ignition Handbook p.550 | 구리 산화물의 반도체성, 알루미늄 산화물의 매우 낮은 전도성, 알루미늄 접점의 금속간화합물 경로 제안 | 문헌 설명으로 보관. 산화막 값에서 `GlowingConnection`을 도출하지 않음. 전류·전력·온도 실험값은 T24 결정에 따라 공통 문턱으로 만들지 않음 |
| Ignition Handbook pp.762–765 | 미국의 1964~1972년 소구경 알루미늄 분기배선, EC-H19·구형 기기·강철 나사와 도금·접속 방식, 후속 장치 표시와 연구 조건 | 설치 지역·기간·도체 등급·크기·단선/연선·접점 모재·도금·방식·용도가 모두 맞을 때만 해당 역사 연구와 연결. 통계·시험 결과를 사건의 고장 확률이나 원인 점수로 사용하지 않음 |

역사 자료는 이후 합금·장치와 대형 인입선의 조건이 다름도 함께 설명한다. 따라서 “알루미늄 배선”, “미국 주택”, “1970년경” 가운데 일부만 맞는 사건에는 그 연구 전체를 적용하지 않는다. 실제 관할 법규나 제품 승인 여부는 사건 시점의 문서로 확인하며, 이 온톨로지는 법규 적합성을 판정하지 않는다.

## 입력 구조

`terminations`에 다음 필드를 추가했다.

| 필드 | 의미 |
|---|---|
| `conductor_material_basis` | 구리·순알루미늄·알루미늄 합금·동피복 알루미늄을 판정한 분석·제조 자료 |
| `conductor_alloy_grade` | `EC-H19`, `AA-8000`처럼 확인된 합금·재료 등급. 재질명에서 자동 생성하지 않음 |
| `conductor_form` | `Solid`, `Stranded`, `Other`, `Unknown` |

`conductorMaterialIdentified`는 확인된 T07 접속 구조에 알려진 도체 재질·크기·형태와 재질 식별 근거가 모두 있을 때 산출된다. `Other`·`Unknown`이나 빈 근거는 자료 완비로 보지 않는다. 순알루미늄을 합금으로 바꾸지 않으며 AWG와 mm²를 자동 환산하지 않는다. 허용전류 산정은 T16의 별도 작업이다.

`mating_contacts`는 실제로 도체와 맞닿는 단자·나사·스프링을 기록한다.

| 필드 | 값·의미 |
|---|---|
| `component`, `termination` | 실제 물리 접점과 그 접속 기록. 접속 단자 자체이거나 단자의 하위 부품이어야 함 |
| `base_material` | `Copper`, `PureAluminum`, `AluminumAlloy`, `CopperAlloy`, `Brass`, `Steel`, `Other`, `Unknown` |
| `surface_coating` | `Zinc`, `Nickel`, `Tin`, `Silver`, `Indium`, `Copper`, `Other`, `None`, `Unknown` |
| `material_basis`, `coating_basis` | 모재와 도금·무도금을 각각 식별한 근거 |

도금 외관이나 자석 반응에서 모재를 자동 결정하지 않는다. T07의 나사 식별 기록과 함께 쓸 수 있지만, 모재와 표면층은 별개 값이다. `assessment_complete: true`에는 같은 접속의 실제 부품·모재·도금과 두 근거가 필요하다.

## 문헌 기준과 적용 범위 대조

`metal_interface_references`는 `ScientificSource`, `HistoricalStudy`, `Manufacturer`, `Standard`, `Other`를 구분한다. 공통 출처·작성 주체 외에 다음 조건을 필요한 만큼 명시한다.

- 도체 재질·등급·크기·형태와 접속 방식
- 맞닿는 접점의 모재·도금
- 설치 지역·적용 기간·분기회로/인입선 용도와 기기 적합 표시
- 도체·접점 산화막의 문헌상 전도 특성과 제안된 발광 경로
- 자료가 실제로 말하는 적용 범위와 제한

`HistoricalStudy`는 지역·시작/끝 연도·용도·도체 크기·형태·접속 방식·접점 모재·도금을 반드시 명시한다. 시작 연도가 끝보다 늦으면 위반이다. `ScientificSource`는 알려진 산화막 특성 또는 제안 경로 설명 중 하나가 필요하다. `Other` 자료는 보관할 수 있지만 적용 완료를 뒷받침하지 않는다.

`metal_interface_comparisons`는 실제 `termination`·`mating_contact`와 하나의 `reference`를 연결한다. 실제 설치 지역·연도·용도와 그 근거, 기기 적합 표시·확인 근거, 접속기기 승인 확인 상태·근거, 적용/제외 근거를 받는다.

`metalInterfaceComparisonSupported`가 산출되려면 다음이 필요하다.

1. 같은 세션·같은 실제 접속의 도체와 접점 재질 기록이 확인돼 있다.
2. 도체 재질·등급·크기·형태, 접속 방식, 접점 모재·도금이 문헌이 제한한 값과 일치한다.
3. 실제 용도와 기기 적합 표시가 알려져 있고, 문헌이 제한한 값과 일치한다.
4. 승인 상태가 `Confirmed` 또는 `ConfirmedAbsent`로 확인되고 각 판단 근거가 있다. 이것은 승인되었다는 뜻이 아니라 상태가 확인됐다는 뜻이다.
5. 역사 연구라면 실제 설치 지역·연도가 문헌의 지역·기간과 일치한다.
6. 문헌 적용 범위와 실제 사건을 대조한 근거가 있다.

문헌과 실제 기록의 등급·크기·지역·표시는 현재 동일 문자열로 대조한다. `US`와 `United States`, AWG와 mm² 같은 표기·단위의 동등성을 추정하지 않으므로 입력에서 같은 기준으로 정규화하고 근거를 남긴다.

기준이 어떤 조건을 명시하지 않았다면 그 조건을 온톨로지가 만들어 제한하지 않는다. 반대로 기준에 조건이 있으면 실제 기록에 같은 값이 없을 때 적용 완료가 성립하지 않는다. `assessment_complete: true`인데 조건이 빠지거나 다르면 SHACL 위반이며, 미완료 기록은 저장하고 추가 확인 질문을 반환한다.

자료 연결 결과는 위험도·발화 원인·법규 적합성의 결론이 아니다. `hasInvestigationRecord`에 저장하고 `hasFact`·`GlowingConnection`·`supportScore`를 새로 만들지 않는다. 맞닿는 접점의 실제 식별 기록은 T06 검증 근거로 인용할 수 있지만 문헌 기준과 적용 검토 의견은 관측 증거로 인용할 수 없다.

## 실행과 검증

```powershell
python scripts/investigate.py examples/investigation_t15.json --output build/investigation_t15_report.json
```

예제의 설비·분석·설치 기록은 합성 자료다. 문헌 기준 두 건은 위 원문의 범위를 구조화한 것이며, 어떤 현장의 고장 가능성이나 제품 적합성을 말하지 않는다. 전용 테스트 **27개 통과(77.83초)**를 확인했다. 합성 예제는 `conforms: true`, 위반·권고 0개, 공급·시간 질문 0개, 세부 확인 질문 1개다. 기존 150건 평가는 정확 126·오판 8·판단보류 16으로 유지됐다. 전체 회귀는 **171개 통과(606.32초)**, OWL 불만족 클래스 **0개**, lint **0건**이다. 로그는 `build/test_t15_full.log`, 현재 규모·집계는 [인계](인계.md)에 기록했다. NFPA 대조표 범위의 하위 절은 **90/100**, Babrauskas 하위 절은 **60/69**다. 이는 각 대조표의 현재 범위이며 TBox 원문 전체 이식 완료를 뜻하지 않는다.
