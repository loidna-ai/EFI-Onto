# 전기화재 조사서 서식 제안 — 이론이 판정 기준으로 삼는데 조사서가 적지 않는 여섯 칸

작성 2026-09-02 · 근거 커밋 `357b3b2` · 검토 대상: 화재조사관

## 1. 이 제안이 나온 자리

EFI-Onto 는 소방청 『화재조사실무Ⅳ』(2025) 와 NFPA 921 의 전기화재 감식 기준을 규칙으로
옮긴 것이다. 이 규칙을 경기 지역 화재조사서 150건(5요인 30건씩)에 돌리면 82.7% 를 맞히고
13.3% 는 원인미상으로 남긴다. 상한은 90.0% — 조사서에 자기 요인의 단서가 하나도 없는
사례는 어떤 규칙으로도 못 맞히기 때문이다.

이 문서는 그 **못 맞히는 쪽**에서 나왔다. 실무Ⅳ 제2편을 목차 단위로 대조해(절 43·하위 절
115) 원문이 판정 기준으로 명시하는데 온톨로지에 자리가 없는 것 8건을 찾았고, 그 8건을
조사서 150건에서 세어 보니 **규칙 문제가 아니라 서식 문제**였다 — 조사관이 그 정보를
적을 칸이 없다. 아래 여섯 칸은 전부 실무Ⅳ 가 감식 포인트로 적어 둔 것이고, 전부 현장에서
보기만 하면 채울 수 있는 것이다.

## 2. 지금 서식

`dataset.xlsx` 기준 슬롯 10개: 추가 계측 · 추가 시각 증거 · 차단기 트립 상태 · 통전 상태 ·
체결 토크 · 절연 손상 이력 · 주변 가연물 · 발화 전 징후 · 환경 오염 · 절연저항.
관찰 전문(자유 서술)은 중앙값 236자, 최소 0자, 최대 1,805자.

150건에서 뽑힌 사실 781개의 확인 상태: **확인됨 777 · 없음 확인 3 · 확인 불가 1.**
조사서가 '없다'를 적을 자리를 주지 않는다는 뜻이다. 온톨로지의 반증 규칙 19개가 150건에서
사실상 발동하지 않는 이유가 이것이다 — 반증은 대부분 '없음 확인'에서 시작한다.

## 3. 제안하는 여섯 칸

| | 칸 | 선택지 | 실무Ⅳ 근거 | 지금 150건 | 무엇을 가르는가 |
|---|---|---|---|---|---|
| A | **특이점이 식별된 대상** | 기기 내부 절연부 / 접속단자·단자대 / 접속부(꼬임·결선) / 배선기구(콘센트·플러그·스위치) / 권선·코일 / 콘덴서 / 전선·코드 중간부 | p.127 표 2-1, p.147·149, p.201 | 서식에 없음. 자유 서술에서 판독기가 121/150 추출 | 트래킹 ↔ 절연열화 ↔ 반단선의 동점. 습기만 적힌 조사서는 기기 안이면 트래킹, 전선이면 절연열화 |
| B | **용융 극** | 한 극만 / 양극 / 미확인 | p.185 ①·⑦㉰·⑧ (세 번 반복) | **1/150.** 접속부·플러그·기판 용흔을 적은 28건이 극을 안 적음 | 한 극 → 접촉불량·반단선·지락, 양극 → 트래킹 |
| C | **탄화부 도통·저항** | 도통(측정값 Ω) / 부도통 / 미측정 | p.243·251·272·299 (기기 넷에서 반복) | **0/150** | 트래킹 탄화도전로의 계측 확인. 수Ω~수십Ω 이면 도전로 |
| D | **접속 방식** (대상이 접속부일 때) | 납땜 / 커넥터 / 꼬임 / 나사·볼트 / 미확인 | p.185 ⑧, p.222, p.237, p.286 | 꼬임 16 · 나사 9 · 커넥터 2 · 납땜 1 — 자유 서술에 흩어짐 | 접촉불량의 자리. 납땜 균열·꼬임 마감은 각각 다른 발열 경로 |
| E | **통전 확인** | 통전 / 비통전 / 확인 불가 + 근거(플러그 삽입·스위치 ON·차단기·목격) | p.178 "통전을 입증하는 것부터 시작한다", NFPA §9.9.1 | 143/150. 미기재 7건 | 전기적 발화의 필요조건. 없으면 확정 불가(C-57). 비통전이면 전기 요인 전부 기각 |
| F | **차단기·퓨즈 상태** | 트립 / 미트립(ON 유지) / 확인 불가 + 종류(MCCB·누전차단기·퓨즈) | p.285 (3), p.203 퓨즈 4형태, NFPA §9.13.2.2 | 51/150 | 퓨즈 용단 형태가 단락·과부하·접촉불량·외부화염을 가른다(p.203). 트립 없음은 압착 반증이 **아니다**(p.285) |

A 는 이미 온톨로지에 있고 판독기가 자유 서술에서 뽑는다. 서식에 칸이 생기면 판독 없이
채워진다. B·C·D 는 온톨로지에 **일부러 넣지 않았다** — 사례가 0~1건이라 규칙을 만들어도
발동할 자리가 없고, 어휘만 만드는 것은 이 프로젝트가 여러 번 되풀이한 실패다. 칸이 생겨
채워지면 그때 만든다.

## 4. 칸보다 중요한 것 — 세 가지 확인 상태

여섯 칸 전부, 그리고 기존 슬롯 전부에 **세 상태**를 둘 것을 제안한다.

```
확인됨   ·   없음 확인   ·   확인 불가
```

이유는 NFPA 921 §19.5 와 논문 3.2절이 같다 — **'확인 불가'는 '없음'이 아니다.** 지금
서식은 둘을 구분할 자리가 없어 조사관이 둘 다 빈칸으로 남기고, 빈칸은 온톨로지에
'확인 불가'로 들어온다. 그래서 '헐거움 없음'(접촉불량 반증), '오염 없음'(트래킹 반증),
'반복 응력 없음'(반단선 반증)이 150건에서 한 번도 확인되지 않았다. 반증이 없으면
가설은 지지점수로만 갈리고, 지지점수가 같으면 원인미상이다.

'없음 확인'을 적으려면 조사관이 그것을 **보고 없다고 판단**해야 한다. 그것이 곧 NFPA 가
말하는 반증 시도(§19.6.4)이고, 이 칸이 그 시도를 서식으로 요구하는 것이다.

## 5. 기대할 수 있는 것과 없는 것

- 원인미상 20건: 반단선 7 · 접촉불량 5 · 절연열화 4 · 트래킹 3 · 압착손상 1.
  반단선 7건은 조사서가 빈약해(비드만, 차단기만) A~F 로도 안 갈린다. 절연열화·트래킹
  동점은 대부분 A(대상)로 갈린다. 접촉불량 5건은 B(용융 극)·D(접속 방식)의 자리다.
- **정확도 숫자를 약속하지 않는다.** 라벨이 조사관 판정이고 5요인 균등 표집이다. 칸이
  채워진 조사서가 30건쯤 모이면 `make calibrate` 로 다시 잰다.
- 칸이 늘면 조사관의 부담이 는다. 여섯 칸 중 B·E·F 는 사진 한 장·확인 하나로 끝나고,
  C 는 회로시험기 한 번이다. A·D 는 선택지 고르기다.

## 6. 검토 방법 — 의견이 아니라 사건을

각 칸에 대해 **반례 사건번호**를 받는다: "이 칸을 적어도 판정에 도움이 안 됐던 사건",
"이 선택지에 안 들어가는 사건". 찬성 의견은 서식을 바꾸지 못하고 사건은 바꾼다.
`build/EFI-Onto_검토표.xlsx` 시트 2~4·6 과 같은 형식이다.
