# 전기화재 조사서 서식 제안 — 현장 검토용 보완 항목

작성 2026-09-02 · 갱신 2026-09-04 (NFPA 추가 본문·T16 허용전류 입력 반영) · 검토 대상: 화재조사관

## 1. 이 제안이 나온 자리

EFI-Onto 는 소방청 『화재조사실무Ⅳ』(2025) 와 NFPA 921 의 전기화재 감식 기준을 규칙으로
옮긴 것이다. 현재 경기 지역 화재조사서 150건(5요인 30건씩) 평가 결과는 일치 126건(84.0%),
오판 8건, 판단보류 16건이다. 판단보류는 미확인 단락 7건과 원인미상 9건을 포함한다.
이는 조사관 라벨과의 비교이며 현장 성능 검증을 대신하지 않는다. 세부 집계는 `cases/baseline.json`에 있다.

이 문서는 그 **못 맞히는 쪽**에서 나왔다. 실무Ⅳ 제2편을 목차 단위로 대조해(절 43·하위 절
115) 원문이 판정 기준으로 명시하는데 온톨로지에 자리가 없는 것 8건을 찾았고, 그 8건을
조사서 150건에서 세어 보니 해당 정보가 거의 기록되지 않았다. 구조화된 입력 칸이 없는 점이
한 원인일 수 있지만, 관찰·계측 자체가 가능했는지는 추가 확인해야 한다. 아래 A~H의 기본 항목과
I~O의 시간·재질·허용전류 항목을 현장에서 시험하고, 확보할 수 없었던 정보도 이유와 함께 기록한다.

## 2. 지금 서식

`dataset.xlsx` 기준 슬롯 10개: 추가 계측 · 추가 시각 증거 · 차단기 트립 상태 · 통전 상태 ·
체결 토크 · 절연 손상 이력 · 주변 가연물 · 발화 전 징후 · 환경 오염 · 절연저항.
관찰 전문(자유 서술)은 중앙값 236자, 최소 0자, 최대 1,805자.

150건에서 뽑힌 사실 781개의 확인 상태: **확인됨 777 · 없음 확인 3 · 확인 불가 1.**
부재 확인 기록이 매우 적다. 반증 규칙 24개 중 이 자료에서 발동한 것은 2개다.
나머지 규칙의 유효성은 이 자료만으로 검증할 수 없다.

발동할 자리가 없고, 어휘만 만드는 것은 이 프로젝트가 여러 번 되풀이한 실패다. 칸이 생겨

과부하는 F(차단기)와 기존 계측 슬롯(부하전류·정격전류, D-1)으로 이미 자리가 있다.
가설이 늘어도 이 칸이 없으면 새 가설은 세워지지 못한다(D-15) — 그래서 정확도가 내려가지
않았지만, 그것은 새 가설이 한 번도 시험되지 못했다는 뜻이기도 하다.

## 4. 확인 상태와 근거

모든 항목에 다음 상태를 구분한다. 빈칸은 `Missing`으로 남긴다.

```
확인됨   ·   없음 확인   ·   확인 불가   ·   미기재
```

NFPA 921 §19.5와 논문 3.2절의 구분대로 **'확인 불가'는 '없음'이 아니다.** 소실·접근 불가·
미측정은 그 이유를 적는다. 현재 판독기는 빈 슬롯에서 사실을 만들지 않으며, 명시적인
확인 불가만 `Unverifiable`로 읽는다. 관찰자, 관찰·계측 시각, 대상 번호, 원문·사진·기록 번호를
각 확인 사실에 연결한다. 목격·추정·계측 결과도 출처에서 구분한다.

'없음 확인'을 적으려면 조사관이 그것을 **보고 없다고 판단**해야 한다. 그것이 곧 NFPA 가
말하는 반증 시도(§19.6.4)이고, 이 칸이 그 시도를 서식으로 요구하는 것이다.

## 6. 현장 검토와 추가 사례 수집

기존 150건의 판단보류는 반단선 6·접촉불량 4·절연열화 4·압착손상 1·트래킹 1건이다.
추가 기록으로 해소되는지 확인하되, 채워지지 않는 사례를 억지로 분류하지 않는다.

- **외부화염·과부하·누전지락·층간단락**으로 판단된 실제 사례를 확보한다. 현재 이 네 라벨은 0건이다.
- 단순 산화물 검출과 접속부 증식, 사후 부식과 발화 전 부식, 순알루미늄과 합금, 사후 차단·리셋을 포함한 사례를 모은다.
- 사건별 원문·사진·계측·시간선과 조사관의 판단 근거를 연결한다. 비식별 사례 ID와 자료 번호를 사용한다.
- 기존 사례의 중복 여부를 확인하고, 새 사례는 규칙을 고치는 자료와 별도 평가 자료로 구분한다.
- 검토 기록에는 `사례 ID / 항목 A~O / 입력 내용·상태 / 근거 자료 / 조사관 판단·이견 / 필요한 수정`을 적는다.

입력 시간, 확인 불가 비율, 판단보류·오판 변화도 함께 확인한다. 확보할 수 없는 항목과 맞지 않는
선택지는 해당 사례로 서식을 고친다. 위 항목으로 성능이 얼마나 개선될지는 아직 검증되지 않았다.

## 7. 검토표와 연결

## D-18 구현에 따른 항목 보완 (2026-09-04)

**P. 회로별 화재 노출 범위 — 국부 / 전반 / 미확인.** 아크 매핑에서 '최하류 지점이 최초 아크'라는 추론
(§9.13.2.1, 실무Ⅰ p.343)은 보호장치가 첫 단락에서 동작한다는 전제 위에 서는데, 강한 화재에 전 구간이
노출된 회로는 거의 동시에 여러 곳에서 아크가 생겨 이 추론이 서지 않는다(Babrauskas p.778). 온톨로지는
회로의 노출이 **국부로 확인**되고 **과전류 보호가 확인**될 때만 단락흔에 발화지점 지시력을 준다(D-10·C-59).
미확인은 국부가 아니다. 조사서 150건에는 이 항목이 0건이다 — 회로별로 적고 근거(연소 범위 사진·전선 소손
구간)를 함께 남긴다. 온도 문턱은 두지 않는다.

**Q. 밀폐형 기기의 용기 밖 경로 — 단자 관통부 / 냉동유 유출 / 외함 용융 / 없음 확인 / 미확인.** 컴프레서처럼
권선이 강판 용기에 밀봉된 기기에서 층간단락을 원인으로 보려면 열·가연물이 용기를 나온 경로가 있어야 한다
(Babrauskas p.755; 실무Ⅳ p.284 사례도 이 경로로 설명된다). 온톨로지는 밀폐형 권선이 확인된 층간단락 결론에
이 근거를 요구한다(C-60). 관찰과 출처(사진 번호)를 함께 적는다.
