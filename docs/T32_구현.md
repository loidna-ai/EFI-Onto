# T32 — 금속물·도전성 액체 혼입

2026-09-04. 국내 분류 표 2-1 '이물 혼입' 갈래를 연다. 사용자 결정: 가설이 아니라 선행 조건 + 분류 도출.

## 원문 대조

| 출처 | 원문 | 온톨로지 |
|---|---|---|
| 실무Ⅳ p.127 표 2-1 사용방법 부적절 | "이물 혼입 — 금속물의 혼입: 전기기기 내에 도전물 혼입" | `ForeignConductorInEquipment` (선행 조건) → `ForeignConductorBridgingArc` (확장 슬롯 메커니즘, ⊑ 단락 아크) |

**표 2-1 은 보고규정의 분류표다.** 감식 기준(어떤 흔적으로 알아보는가)을 주는 본문 절이 없다. 그래서 가설로
올리지 않는다 — 단서를 지어내야 하기 때문이다. '미확인 단락'을 가설이 아니라 판단보류의 국내 분류 이름으로
둔 것(D-14)과 같은 층에 둔다.

## 구현

- **D-19** `ForeignConductorIntrusionDerivationRuleShape`: 원인미상 + 단락흔 확인 + 통전 확인 + 기기 내 도전물 혼입
  **확인** → `outcomeForeignConductorIntrusion`. D-14 의 출력에 기대지 않고 전제를 직접 읽는다(같은 `sh:order`
  의 도형끼리 실행 순서가 정해지지 않는다). `Session.outcome()` 이 같은 판정을 낸다 — 미확인 단락 안에서
  혼입이 확인된 부분집합.
- 금속물 메커니즘은 어떤 가설도 선언하지 않는다 → `compatibility` 가 압착·반단선으로 새지 않고, 혼입 확인이
  어떤 가설도 세우거나 점수를 주지 않는다. lint 의 확장 슬롯 목록에 있다.
- 액체는 습기 노출의 하위라 cause_audit 판정을 '공유'로 물려받는다.

## 판단 경계

- **금속물 존재만으로 단락을 확정하지 않는다.** 단락흔·통전 확인이 같이 있어야 하고, 그래도 분류이지 가설이 아니다.
- **사후 혼입은 선행 조건이 아니다.** 소화수·낙하물은 발화 전 존재가 아니다. 확인 상태가 그것을 든다(P4).
- 사례 150건에 0건. 평가는 움직이지 않는다. 조사서 서식에 '기기 내 이물' 항목(R)을 제안한다.
- 사례·단서가 생기면 열 번째 가설로 올릴 수 있다 — 그때 배타 공리·열거형·변별력 공식의 N 을 함께 본다.
