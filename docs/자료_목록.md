# 구해야 할 자료 — 온톨로지의 어디를 채우는가 기준

작성 2026-09-02. 서지 사항 중 **(확인)** 표시는 기억에 의존한 것이라 받기 전에 확인할 것.
받으면 `nfpa.py`·`silmu.py` 와 같은 절 단위 대조표를 하나씩 만든다. 국내 교재와 갈리는
곳은 덮어쓰지 않고 둘 다 적는다(`dcterms:references`).

우선순위는 "온톨로지의 검증되지 않은 부분을 얼마나 직접 채우는가"다. 검증되지 않은 부분은
교재 이식률이 아니라 **작성자가 구성한 인과 사슬**(어떤 흔적을 누가 내는가, 화재 자체도 내는가)이고,
그 답은 요인별 서술인 국내 교재에는 없다.

## 받은 뒤의 절차

1. 원문 전체를 받는다. 발췌로 붙이지 않는다(인계 7장 ⑪).
2. 자료마다 대조표 스크립트 하나 — `scripts/<자료>.py`, `SECTIONS`/`SUBSECTIONS`/상태 5종.
3. 국내 교재와 갈리면 둘 다 적고 `dcterms:references` 로 출처를 나눈다.
4. 붙이기 전에 두 질문 — 이 흔적을 화재 자체가 내는가 / 정말 그 요인에서만 일어나는가.
5. `score.py --write` → `make test` → `make calibrate` → `make refute`.
